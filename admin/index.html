Recorded visits

A visit is one browser on one US Eastern calendar day. Reloading the page does not add another visit. The same browser counts again on a later day. Bots, prefetched pages, this admin page, and local development are not included.

LinkedIn is a visit from a link with utm_source=linkedin, and also a visit to the plain portfolio address when the browser reports that the person came from LinkedIn. Résumé uses utm_source=resume. Direct means no campaign parameter and no outside referrer. Other is everything else, so those visits stay in the total.

A visit is stored only when the request includes this site's own page address, so the source can be checked. The server keeps a one-way daily hash only long enough to ignore a repeat visit that day, then deletes it. It does not store the IP address, user agent, referrer, or page URL. A failed save is omitted. Percentages appear after 20 visits in that period. Anyone who loads the public site can add a visit, so this is a record of daily browsers, not a verified headcount.
