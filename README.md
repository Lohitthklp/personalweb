## Run locally

This is a static site. Open `index.html` in a browser, or serve the folder with any static file server, for example:

```bash
npx --yes serve .
```

## Stack

- HTML, CSS, vanilla JavaScript
- [Anime.js](https://animejs.com/) for motion

## Branches

- **`main`** — current site
- **`legacy-main`** — snapshot of the earlier `main` history
